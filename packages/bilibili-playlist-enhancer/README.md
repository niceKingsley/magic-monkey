# bilibili-playlist-enhancer

> **哔哩哔哩（Bilibili）多场景播放列表 / 选集 / 合集增强助手（番剧、课程、视频稍后再看不会兼容）**
>
> 重写一套接近B站的侧边选集面板 UI，将合集浏览、智能随机、即时搜索、自定义快捷键、动态高亮与播放规则深度整合，提高您的听歌与学习体验🤗

## ✨ 功能详解

### 1. 🔀 随机播放模式

- **候选池抽取**：优先从未播放视频池中随机抽取，已播放过的视频不会重复切入，全部播完后自动开启新一轮轮转。
- **围灵活配置**：支持「全合集随机」与「仅当前分组随机」，音乐合辑与分段长剧皆可轻松应对。
- **历史回溯栈**：支持上一集回退到刚随机过的上一首，下一集继续探索新视频。

### 2. 🔍 列表内即时搜索与过滤

- **毫秒级即时过滤**：输入关键词瞬间动态缩减列表，丝滑无卡顿。
- **多维度智能匹配**：支持主视频标题、子分 P 标题以及 `p1`、`p2` 序号格式快速模糊匹配。
- **自动定位命中分 P**：搜索命中目标时，自动定位并直观高亮展示。
- **结果计数与快捷键**：实时展示匹配统计徽章（如 `N 个结果` / `无结果`），支持一键清空与 `Esc` 快捷退出。

### 3. ⌨️ 支持自定义切集快捷键

- **键位自定义设置**：在设置中可找到键位录制模式，按下键盘上的任意单个按键即可绑定为你的专属切集键。

### 4. 🎯 播放状态实时高亮与自动居中

- **动态跳动指示**：当前正在播放的单集或子分 P 带有动态跳动的播放指示图标，一眼即可识别当前进度。
- **平滑自动居中**：切集或加载页面后，列表容器自动平滑滚动并将当前播放项定位在可视区域中央，无需手动滚动查找。

### 5. 🔄 列表排序

- 提供多种排序方式，支持在以下模式间一键切换：
  - **官方排序**：保持 UP 主或官方预设的播放顺序。
  - **最新发布优先**：最新更新的视频置顶，方便追更最新期。
  - **最早发布优先**：从最早发布的单集开始按时间线顺序排列。
