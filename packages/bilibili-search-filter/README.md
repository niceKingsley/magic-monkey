# bilibili-search-filter

> **哔哩哔哩（Bilibili）搜索结果过滤增强助手**
>
> 自动过滤搜索结果中的无关视频（综合/视频的区域），支持标题/UP主匹配、一键查看已过滤内容与白名单放行，让搜索结果更精准干净🤗

---

## ✨ 主要功能

### 1. 🎯 搜索结果精准过滤

- **隐藏无关视频**：自动过滤未命中搜索词的卡片，去除广告与无关算法推荐。
- **匹配标题与 UP 主**：支持自定义匹配范围，命中 UP 主时自动高亮标记。

### 2. 📊 过滤统计与一键比对

- **实时统计栏**：列表顶部直观显示已过滤与保留数量。
- **一键查看已过滤**：点击快速切换显示/隐藏被过滤的卡片，支持半透明区分。

### 3. 🛡️ 关键词白名单

- **搜索词免过滤**：命中白名单关键词时自动放行全部结果。
- **便捷管理**：支持标签直观增删，以及分号/换行批量编辑。

### 4. ⚡ 自动展开更多筛选

- **进页面自动展开**：进入搜索页自动展开官方筛选面板（分区、时长等），省去手动点击。
