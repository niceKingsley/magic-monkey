# bilibili-danmaku-filter

> **哔哩哔哩（Bilibili）弹幕过滤与清洗助手**
>
> 自动合并相近刷屏弹幕、过滤低质灌水弹幕，支持权重阈值设置和黑名单过滤与规则导入导出，为你营造清爽舒适的弹幕环境🤗

---

## ✨ 主要功能

### 1. 🔀 相似弹幕合并与防刷屏

- **智能合并重复内容**：将短时间窗口内出现的相同或高度相似的弹幕聚合合并为 1 条，优先保留更完整的文本，告别复读刷屏。
- **灵活调节门槛**：可自由调整相似度严格程度与时间窗口，兼顾热闹氛围与清晰画面。

### 2. 🛡️ 低质弹幕过滤

- **权重质量过滤**：自动过滤评分较低的水军、广告或无意义灌水弹幕，只留下优质弹幕内容。

### 3. 📺 视频与直播双支持

- **多场景独立配置**：视频播放页与直播间弹幕支持独立开启过滤、设置各自的防刷屏参数与黑名单。

### 4. 🚫 黑名单规则管理

- **多种匹配模式**：支持包含关键词、完全匹配、正则表达式三种屏蔽方式。
- **安全防误杀**：正则输入自带格式校验，避免误屏蔽全量弹幕。

### 5. 📦 规则导入、导出与互相同步

- **一键备份导出**：将当前黑名单规则导出为 JSON 文件，换设备或分享规则更轻松。
- **文件导入去重**：支持直接上传导入规则文件，自动去重并剔除无效规则。
- **跨端一键合并**：支持将「视频黑名单」与「直播黑名单」一键相互合并，无需手动重复录入。
